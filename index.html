Deploy Cheatsheet Free hosting by what you're shipping, with the catch on every card · checked Oct 2026

FrontendStatic sites, React, Next.js
No card
Git push to deploy
Vercel
Connect the repo and every push deploys. Best for React, Next.js, or any static site.
CatchHobby plan is non-commercial. 100 GB bandwidth a month.
vercel.com → No card
Fastest CDN
Cloudflare Pages
Unlimited static requests on a global edge. Pairs with Workers when you need an API next to it.
Catch500 builds a month. Functions count against the Workers free quota.
pages.cloudflare.com → No card
Zero setup
GitHub Pages
Serve a static build straight from the repo you already have. Ideal for a portfolio or docs site.
CatchStatic only, public repos only, 1 GB site limit.
pages.github.com →
Backend / APIPython, Node, Docker services
No card
Long-running server
Render
Web services, cron jobs, and Docker containers from a repo. The default for a Flask or FastAPI backend.
CatchSleeps after 15 min idle and takes about a minute to wake. Free Postgres expires after 30 days.
render.com → No card
Edge functions
Cloudflare Workers
Lightweight APIs and automation scripts at the edge. No cold starts, global by default.
Catch100k requests a day. 10 ms CPU per request, so no heavy Python.
workers.cloudflare.com → Trial
Trial credit
Railway
Server plus Postgres in one project with the smoothest developer experience of the three.
Catch$5 one-time trial for 30 days, then $1 a month of credit. Plan on Hobby at $5 a month to keep a demo up.
railway.com →
DatabaseFree Postgres that outlives the demo
No card
Serverless Postgres
Neon
Postgres that scales to zero. Branch the database like code for test data.
Catch0.5 GB storage and 100 compute hours a month per project.
neon.tech → No card
Postgres + auth + storage
Supabase
A whole backend: Postgres, auth, file storage, and a REST API generated from your schema.
CatchProjects pause after 7 days without traffic. Un-pause from the dashboard before a demo.
supabase.com → No card
No time limit
Aiven
A plain managed Postgres (or MySQL) that stays free indefinitely with no sleep.
CatchOne small instance, about 1 GB, and it is a tiny shared CPU.
aiven.io →
AI / ML demoGradio and Streamlit apps
No card
GPU demos
Hugging Face Spaces
Host a Gradio demo with on-demand GPU through ZeroGPU and share a public link.
CatchFree accounts get 2 Gradio Spaces on ZeroGPU only. Free CPU and Docker Spaces ended in July 2026.
huggingface.co/spaces → No card
Streamlit apps
Streamlit Community Cloud
One-click hosting for a Streamlit dashboard from a public GitHub repo.
CatchPublic repos only. Apps sleep after inactivity and wake on the next visit.
streamlit.io/cloud → No card
Model API
Cloudflare Workers AI
Call open models (Llama, Whisper, embeddings) from a Worker without hosting anything.
Catch10k neurons a day free, roughly a few hundred chat calls. Not for fine-tuned models.
